## Junior: «Читаю структуры и документирую по шаблону»

На Junior-уровне JSON/XML — это **язык, на котором передаются данные**. Вы учитесь читать JSON-ответы, разбирать XML-документы, различать типы данных и документировать структуры по готовому шаблону. Ключевой сдвиг: вы перестаёте «пересказывать» данные и начинаете **документировать их контракт** — какие поля есть, какие типы, обязательные или опциональные.

**Что входит в Junior-уровень:**

- **JSON-синтаксис:** вы понимаете структуру JSON: объекты `{}`, массивы `[]`, пары «ключ-значение», строки, числа, булевы значения, `null`. Вы различаете вложенные объекты и массивы объектов.
- **XML-синтаксис:** вы понимаете структуру XML: корневой элемент, вложенные элементы, атрибуты, текстовое содержимое.
- **Типы данных:** вы различаете в JSON: string, number, boolean, array, object, null. В XML: элементы, атрибуты, текст, CDATA. Вы документируете типы для каждого поля.
- **Обязательные и опциональные поля:** вы понимаете, какие поля обязательны, а какие — нет. Вы документируете это явно.
- **Документирование структур:** вы описываете JSON/XML по шаблону: поле → тип → описание → пример.
- **Валидация примеров:** вы проверяете, что ваши примеры JSON/XML валидны — синтаксически корректны и соответствуют реальному API.

*Ключевой принцип Junior: вы **читаете и документируете** структуры данных, а не проектируете их. Если поле неверное — вы документируете то, что есть, и уточняете у разработчика.*

### Курсы и книги (Junior)

[Learn API Technical Writing: JSON and XML for Writers (Udemy, Peter Gruenbaum)](https://www.udemy.com/course/learn-api-technical-writing-json-and-xml-for-writers/) - Курс **специально для технических писателей**: 8 видео, 4 практических упражнения, 5 квизов. Учит читать и документировать структурированные данные в JSON и XML. Не требует опыта программирования;

[API Technical Writing: JSON and XML for Writers (Koenig Solutions)](https://www.koenig-solutions.com/api-technical-writing-json-xml-training) - 8-часовой интенсив: API types (REST, SOAP, GraphQL), JSON syntax, XML tags and attributes, hands-on practice, documenting errors;

[API Technical Writing Made Easy: A Guide to JSON & XML for Non-Programmers (R. Parvin)](https://www.amazon.com/API-Technical-Writing-Made-Easy-ebook/dp/B0BQZ8Z8Z8) - Практическое руководство **без опыта программирования**: что такое API, как читать JSON/XML, как документировать структуры;

[JSON and XML for Technical Writers (Class Central)](https://www.classcentral.com/course/udemy-learn-api-technical-writing-json-and-19418) - Обзорный курс: read and understand structured data, write documentation for JSON/XML files, edit JSON/XML for tools that generate documentation;

[JSON Schema vs XML Schema (Stack Overflow)](https://stackoverflow.com/questions/13217291/json-schema-vs-xml-schema) - Понимание разницы между схемами: JSON Schema draft 04 vs XSD, когда что использовать.
