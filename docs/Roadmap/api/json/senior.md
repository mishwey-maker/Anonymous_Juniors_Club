## Senior: «Определяю стандарт и управляю схемами»

На Senior-уровне JSON/XML становится **элементом архитектуры данных**. Вы не просто документируете структуры, вы **влияете на их дизайн** с точки зрения документируемости. Вы определяете стандарты схем, управляете валидацией, обеспечиваете консистентность между продуктами.

**Что входит в Senior-уровень:**

- **Стратегия схем:** вы определяете, какие схемы (JSON Schema, XSD) используются в организации, как они версионируются, как поддерживаются в актуальном состоянии.
- **Governance:** вы определяете политику: кто отвечает за актуальность схем, как проверяется соответствие документации и реального API, как обрабатываются breaking changes в структурах данных.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых endpoints, версий, форматов без ручной работы.
- **Стандарты документирования:** вы определяете, как описывать JSON/XML в документации: обязательные поля, примеры, ограничения, обработка ошибок.
- **Автоматизация:** вы настраиваете CI/CD для валидации: проверка схем, валидация примеров, проверка соответствия документации и спецификации.
- **Обучение:** вы обучаете команды работе со схемами, проводите воркшопы, создаёте внутренние стандарты.
- **Влияние на дизайн API:** вы участвуете в API-ревью, предлагаете улучшения структур данных с точки зрения документируемости.

*Ключевой принцип Senior: вы **определяете правила игры** и **отвечаете за их соблюдение в масштабе**. Инженеры приходят к вам за советом по структурам данных **до** начала разработки.*

### Курсы и книги (Senior)

[Pro RESTful APIs (Sanjay Patni, продвинутые главы)](https://link.springer.com/book/10.1007/978-1-4842-2764-0) - Главы о дизайне, построении и интеграции с REST, JSON, XML;

[Java XML and JSON (Jeff Friesen)](https://link.springer.com/book/10.1007/978-1-4842-1464-1) - Продвинутое руководство по обработке XML и JSON: parsing, creating, transforming, validation;

[JSON Schema: A Media Type for Describing JSON Documents (IETF)](https://datatracker.ietf.org/doc/html/draft-bhutton-json-schema-00) - Официальная спецификация JSON Schema: understanding, composition, validation;

[W3C XML Schema Definition Language (XSD) 1.1](https://www.w3.org/TR/xmlschema11-1/) - Официальная спецификация XSD 1.1: structures, datatypes, validation;

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды.
