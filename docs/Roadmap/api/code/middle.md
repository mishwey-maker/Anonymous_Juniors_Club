## Middle: «Проектирую портфель примеров и автоматизирую проверки»

На Middle-уровне примеры кода перестают быть просто «дополнением к документации». Теперь это **предмет проектирования**: вы определяете, какие примеры нужны для разных аудиторий, как они связаны с задачами разработчиков, как автоматизировать их проверку.

**Что входит в Middle-уровень:**

- **Портфель примеров (Code Sample Portfolio):** вы проектируете три уровня примеров: **request snippets** (один вызов), **task-focused examples** (несколько вызовов для решения задачи), **sample applications** (end-to-end приложение).
- **Мультиязычность:** вы добавляете примеры на нескольких языках (curl, Python, JavaScript, Java) в зависимости от аудитории.
- **Безопасность и обработка ошибок:** вы включаете в примеры безопасную обработку credentials (никогда не хардкодить токены), таймауты, проверку статус-кодов, обработку ошибок.
- **Автоматизация проверок:** вы настраиваете CI для тестирования примеров: синтаксическая проверка — минимум, высокоценные примеры запускаются против контролируемой среды.
- **Интеграция с OpenAPI:** вы используете `x-codeSamples` для добавления примеров в спецификацию OpenAPI. Swagger UI и Redoc автоматически отображают примеры для каждого эндпоинта.
- **Проверка актуальности:** вы убеждаетесь, что примеры не используют устаревшие SDK, не игнорируют ошибки и не нормализуют небезопасные практики.

*Ключевой принцип Middle: вы **проектируете и автоматизируете**. Вы отвечаете за то, чтобы примеры были актуальными, безопасными и проверяемыми.*

### Курсы и книги (Middle)

[Google Technical Writing Two — Code Samples](https://developers.google.com/tech-writing/two) - Продвинутые темы: создание примеров для туториалов, антипримеры, диапазон сложности;

[Mintlify: Add SDK examples](https://mintlify.com/docs/api-playground/sdk-examples) - Как добавлять SDK-примеры через `x-codeSamples`, автоматическая генерация через Speakeasy;

[Redocly: x-codeSamples](https://redocly.com/docs/openapi-visual-reference/x-code-samples/) - Использование `x-codeSamples` для добавления кастомных примеров на нескольких языках;

[API7.ai: Incorporating Code Samples](https://api7.ai/blog/code-samples-in-api-documentation) - Продвинутые разделы: портфель примеров, мультиязычность, автоматизация проверок;

[Postman: Create examples of request responses](https://learning.postman.com/docs/sending-requests/examples/) - Как использовать Postman для создания и сохранения примеров запросов и ответов.
