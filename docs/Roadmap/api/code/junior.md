## Junior: «Пишу работающие примеры по шаблону»

На Junior-уровне примеры кода — это **практический инструмент**, который вы добавляете в документацию по готовому шаблону. Вы учитесь писать примеры, которые **работают**: их можно скопировать, запустить и получить ожидаемый результат. Ключевой сдвиг: вы перестаёте «пересказывать» API словами и начинаете **показывать** его в действии.

**Что входит в Junior-уровень:**

- **Базовые примеры для эндпоинта:** вы пишете пример запроса (curl) и пример ответа (JSON) для каждого документируемого эндпоинта.
- **Самодостаточность:** каждый пример должен быть **self-contained** — его можно скопировать и запустить без дополнительных пояснений. Это означает: явные заголовки авторизации, полные URL, корректный JSON.
- **Форматирование:** вы следуете правилам оформления кода: отступы, переносы строк (80 символов), указание языка для подсветки синтаксиса, использование комментариев для пропущенного кода.
- **Интро-предложение:** вы предваряете каждый пример кода вводным предложением, которое объясняет, что этот пример делает.
- **Проверка работоспособности:** вы тестируете каждый пример через Postman или curl, чтобы убедиться, что он действительно работает и возвращает ожидаемый результат.

*Ключевой принцип Junior: вы **пишете и проверяете** примеры, а не копируете их из кода. Если пример не работает — вы это находите и исправляете.*

### Курсы и книги (Junior)

[Google Technical Writing One — Code Samples](https://developers.google.com/tech-writing/one) - Официальный модуль по оформлению примеров кода: интро-предложения, отступы, переносы строк, комментарии к пропущенному коду;

[Google Developer Documentation Style Guide — Code Samples](https://developers.google.com/style/code-samples) - Эталонные правила оформления: отступы, переносы строк, использование комментариев, запрет на ellipsis;

[API7.ai: Incorporating Code Samples in API Documentation](https://api7.ai/blog/code-samples-in-api-documentation) - Практические рекомендации: самодостаточность примеров, явные предпосылки, тестирование примеров;

[Mintlify: API Documentation Recommendations](https://mintlify.com/blog/api-documentation) - Раздел о code samples: как примеры ускоряют time-to-first-call, примеры из Stripe и Twilio;

[Document360: Writing Technical Guides for Developers](https://document360.com/blog/technical-writing-guides/) - Раздел о code examples: используйте реальный работающий код, показывайте вывод, добавляйте copy buttons.
