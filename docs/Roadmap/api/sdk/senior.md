## Senior: «Определяю стандарт и управляю lifecycle»

На Senior-уровне SDK-документация становится **элементом developer experience (DX) стратегии**. Вы не просто проектируете документацию для одного SDK, вы определяете, как компания подходит к SDK-документации в масштабе: стандарты, автоматизация, метрики, обучение.

**Что входит в Senior-уровень:**

- **Стратегия SDK-документации:** вы определяете, какие SDK нуждаются в документации, какие языки поддерживаются, как документация связана с API reference и migration guides.
- **Governance:** вы определяете политику: кто отвечает за актуальность, как проверяется работоспособность примеров, как обрабатываются breaking changes в SDK.
- **Стандарты:** вы определяете, как организуется SDK-документация: структура навигации, обязательные разделы, шаблоны, стиль примеров кода.
- **Автоматизация:** вы настраиваете пайплайн: генерация reference из docstrings → валидация примеров → публикация. Вы выбираете инструменты: TypeDoc, DocFX, Javadoc, Sphinx, phpDocumentor.
- **Метрики:** вы измеряете эффективность SDK-документации: time-to-first-call, adoption, support tickets, DX-метрики.
- **Обучение:** вы обучаете команды написанию SDK-документации, проводите воркшопы, создаёте внутренние стандарты.
- **Влияние на дизайн SDK:** вы участвуете в design-ревью SDK, предлагаете улучшения API с точки зрения документируемости и пользовательского опыта.

*Ключевой принцип Senior: вы **определяете правила игры** и **отвечаете за их соблюдение в масштабе**. SDK-документация становится частью DX-стратегии, а не побочным продуктом разработки.*

### Курсы и книги (Senior)

[developer-docs-framework: SDK docs (GitHub)](https://github.com/ann-kilzer/developer-docs-framework) - Enterprise-фреймворк для документации: 14 content types, включая SDK docs. Content architecture, docs-as-code workflows, DX strategy;

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды;

[Mintlify: Create developer documentation](https://mintlify.com/) - Построение developer documentation: quickstarts, references, guides для SDK;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации, включая SDK и governance;

[Google Developer Documentation Style Guide](https://developers.google.com/style) - Эталонные правила для developer documentation, включая code samples и reference.
