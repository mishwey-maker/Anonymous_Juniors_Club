## Senior: «Влияю на дизайн API и определяю стандарт»

На Senior-уровне REST/HTTP становится **элементом архитектуры продукта**. Вы не просто документируете API, вы **влияете на его дизайн** с точки зрения документируемости. Вы определяете стандарты, обучаете команды, обеспечиваете консистентность между продуктами.

**Что входит в Senior-уровень:**

- **Дизайн API с точки зрения документируемости:** вы участвуете в API-ревью, предлагаете улучшения: консистентные имена ресурсов, понятные коды ошибок, предсказуемое поведение.
- **Стандарты документации API:** вы определяете, какие разделы обязательны для каждого эндпоинта, какие примеры нужны, как описывать ошибки.
- **Governance:** вы определяете политику: кто отвечает за актуальность документации API, как проверяется соответствие спецификации, как обрабатываются изменения.
- **Масштабирование:** вы проектируете систему документации, которая выдерживает рост: добавление новых endpoints, версий, языков без ручной работы.
- **Автоматизация:** вы настраиваете CI/CD для документации API: генерация из OpenAPI, валидация, линтинг, публикация.
- **Обучение:** вы обучаете команды документированию API, проводите воркшопы, создаёте внутренние стандарты.
- **Метрики:** вы измеряете эффективность документации API: time-to-first-call, support tickets, adoption.

*Ключевой принцип Senior: вы **определяете правила игры** и **отвечаете за их соблюдение в масштабе**. PM-ы и инженеры приходят к вам за советом по API-дизайну **до** начала разработки.*

### Курсы и книги (Senior)

[Specialization in API Documentation (UW Professional & Continuing Education)](https://www.pce.uw.edu/specializations/api-documentation) - 11-недельная программа для технических писателей: API fundamentals, OpenAPI, docs-as-code, testing. Практика с industry-standard tools: OpenAPI Specification, Swagger UI, Markdown, Postman;

[RESTful Web Services (Leonard Richardson, Sam Ruby)](https://www.oreilly.com/library/view/restful-web-services/9780596529260/) - Классика: дизайн ресурсов, правильное использование HTTP и hypermedia links;

[REST API Design Rulebook (Mark Masse)](https://www.oreilly.com/library/view/rest-api-design/9781449317904/) - Правила дизайна REST API: URI, методы, статус-коды, представления;

[Pro RESTful APIs (Sanjay Patni)](https://link.springer.com/book/10.1007/978-1-4842-2764-0) - Дизайн, построение и интеграция с REST, JSON, XML;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации, включая API и governance.
