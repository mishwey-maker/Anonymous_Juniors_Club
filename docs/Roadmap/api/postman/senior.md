## Senior: «Определяю стандарт и управляю lifecycle тестирования»

На Senior-уровне Postman становится **элементом инфраструктуры качества документации**. Вы не просто пишете тесты, вы **управляете lifecycle**: определяете стандарты, обучаете команды, интегрируете тестирование в процесс разработки и документации.

**Что входит в Senior-уровень:**

- **Стратегия тестирования API:** вы определяете, как тестирование API вписывается в общую стратегию документации: какие эндпоинты тестируются, как часто, кем, с какими проверками.
- **Governance:** вы определяете политику: кто отвечает за актуальность тестов, как обрабатываются breaking changes, как тесты связаны с документацией.
- **Стандарты коллекций:** вы определяете, как организуются коллекции Postman: структура папок, именование запросов, обязательные тесты, использование переменных.
- **CI/CD-интеграция:** вы проектируете пайплайн: при изменении API запускаются тесты Postman, при изменении документации — проверка соответствия.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых API, версий, команд без ручной работы.
- **Обучение:** вы обучаете команды работе с Postman, проводите воркшопы, создаёте внутренние стандарты.
- **Влияние на дизайн API:** вы используете данные тестирования для влияния на дизайн API: если эндпоинт сложно тестировать, он сложен и для документирования.

*Ключевой принцип Senior: вы **определяете правила игры** и **отвечаете за их соблюдение в масштабе**. Тестирование API становится частью процесса разработки, а не разовым действием.*

### Курсы и книги (Senior)

[API Testing and Development with Postman (IEEE, продвинутые модули)](https://iln.ieee.org/courses/api-testing-and-development-with-postman) - Advanced topics: data-driven and contract testing, workflow automation, mock servers, security and performance testing;

[Mastering Postman (Dave Westerveld, продвинутые главы)](https://www.oreilly.com/library/view/mastering-postman/9781838987562/) - Главы об API governance, интеграции, публикации, Postman CLI для продвинутой автоматизации;

[Postman Docs: API Governance](https://learning.postman.com/docs/api-governance/) - Как управлять стандартами API в организации: правила, линтинг, соответствие;

[Postman Docs: CI/CD Integration](https://learning.postman.com/docs/running-collections/using-newman-cli/continuous-integration/) - Как интегрировать Postman/Newman в CI/CD: GitHub Actions, Jenkins, GitLab CI;

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды.
