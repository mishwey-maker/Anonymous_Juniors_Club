## Junior: «Отправляю запросы и проверяю документацию»

На Junior-уровне Postman — это **инструмент проверки**. Вы учитесь отправлять запросы, читать ответы и убеждаться, что документация соответствует реальному поведению API. Ключевой сдвиг: вы перестаёте писать документацию «по памяти» и начинаете **валидировать её через реальные вызовы**.

**Что входит в Junior-уровень:**

- **Интерфейс Postman:** вы понимаете структуру: workspace, collections, folders, requests, environments. Вы знаете, как создать новый запрос, выбрать метод и отправить его.
- **Работа с запросами:** вы добавляете URL, query parameters, path parameters, headers (Content-Type, Accept, Authorization), body (raw JSON).
- **Анализ ответов:** вы читаете статус-код, заголовки ответа, тело ответа. Вы проверяете, соответствует ли ответ документации: тот ли статус-код, те ли поля, те ли типы данных.
- **Коллекции:** вы умеете импортировать API-коллекции, добавлять папки, сохранять запросы и ответы в коллекцию.
- **Переменные:** вы понимаете, зачем нужны переменные (base URL, токены), и умеете их создавать. Environment variables позволяют переключаться между средами.
- **Валидация документации:** вы проходите по документации шаг за шагом, отправляя каждый запрос. Если что-то не совпадает — вы фиксируете это и уточняете у разработчика.

*Ключевой принцип Junior: вы **проверяете** документацию, а не пишете её «вслепую». Если пример в документации не работает — вы это находите.*

### Курсы и книги (Junior)

[Postman Academy: API Fundamentals Student Expert Certification](https://academy.postman.com/) - Официальная сертификация Postman: GET, POST, PUT, PATCH, DELETE, работа с JSON, path variables, query parameters. Полностью бесплатно, с бейджем и сертификатом;

[Technical Writing: How to Write API Software Documentation (Udemy)](https://www.udemy.com/course/technical-writing-how-to-write-api-software-documentation/) - Курс **специально для технических писателей**: использует Postman для проверки функциональности API. Не требует опыта программирования;

[Apply API Testing Fundamentals Using Postman (Coursera)](https://www.coursera.org/learn/api-testing-postman) - Install and configure Postman to create, organize, and execute REST API requests. Validate API responses, debug issues, write test scripts;

[Postman Learning Center](https://learning.postman.com/) - Официальная документация Postman: от первых шагов до продвинутых сценариев;

[Postman: The Complete Guide — REST API Testing (Udemy)](https://www.udemy.com/course/postman-the-complete-guide/) - Курс для тестировщиков и разработчиков, но подходит писателям: GET, POST, PUT, DELETE, JSON, аутентификация, работа с коллекциями.
