## Junior: «Пишу и вижу результат»

На Junior-уровне редактор — это ваш основной инструмент. Вы должны уверенно работать в VS Code (или выбранном редакторе) с Markdown: писать текст, видеть превью, использовать базовые расширения. Ключевой сдвиг: вы перестаёте писать «в блокноте» и начинаете использовать среду, которая помогает вам не ошибаться.

Что входит в Junior-уровень:

* **Базовая настройка VS Code:** установка, настройка шрифта и размера, понимание интерфейса (Explorer, Search, Source Control, Extensions).

* **Markdown-расширения:** Markdown All in One (автогенерация TOC, горячие клавиши, автоматическая нумерация заголовков), Markdown Preview Enhanced (поддержка LaTeX, Mermaid, экспорт в PDF/HTML), Code Spell Checker (проверка орфографии с кастомным словарём для технических терминов).

* **Превью:** умение открыть превью Markdown (Ctrl+Shift+V), понимание разницы между превью и финальным рендерингом на платформе.

* **Горячие клавиши:** базовые сочетания (Ctrl+P — быстрый переход к файлу, Ctrl+Shift+P — палитра команд, Ctrl+D — мульти-курсор для одновременного редактирования одинаковых слов).

* **Работа с файлами:** создание, переименование, перемещение файлов внутри проекта, понимание структуры папок документации.

*Ключевой принцип Junior: вы используете редактор так, как он настроен. Если в команде принят VS Code с определённым набором расширений — вы работаете именно в нём, не переключаясь на «свой любимый блокнот».*

## Курсы и книги (Junior)

[VS Code официальная документация](https://code.visualstudio.com/docs) - Официальный гайд по настройке: от установки до горячих клавиш. Разделы «Get Started» и «Tips and Tricks» — обязательны для старта;

[«VSCode for Technical Writing:](https://m.php.cn/faq/1948549.html) - Подробный разбор настройки VS Code именно для технического писателя: расширения Markdown All in One, Markdown Preview Enhanced, Code Spell Checker, Prettier и Vale, а также рабочие процессы с Git и Live Server;

[Setup and Configuration для docs-as-code](https://josephstreeter.github.io/docs/) - Пример документационного сайта на DocFX с полным списком расширений и конфигураций для docs-as-code проектов. Исходный репозиторий с настройками VS Code доступен на GitHub;

[GitHub Skills: Introduction to GitHub](https://skills.github.com/) - Интерактивный курс прямо внутри GitHub, который поможет понять, как редактор связан с Git-воркфлоу. Начните с урока «Introduction to GitHub», затем переходите к «Review pull requests».
