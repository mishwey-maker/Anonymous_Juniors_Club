## Senior: «Определяю стандарт и масштабирую»

На Senior-уровне Git — это элемент архитектуры документации. Вы не просто выбираете стратегию для команды, вы определяете, как Git вписывается в общую стратегию: как связаны рукописные гайды и генерируемый reference, как масштабируется документация на десятки тысяч файлов, как обеспечивается traceability и compliance.

Что входит в Senior-уровень:

* **Архитектура репозитория:** вы проектируете структуру репозитория для масштабируемой документации: модульная организация, мультиязычность, разделение на гайды и reference.

* **Git-воркфлоу для организации:** вы определяете, как работают несколько команд в одном репозитории или в связанных репозиториях, как координируются изменения, как разрешаются конфликты между командами.

* **Compliance и traceability:** в регулируемых отраслях (медицина, финансы) вы настраиваете Git для соответствия стандартам: подписанные коммиты (GPG), связывание с issues, аудит изменений.

* **Автоматизация на уровне организации:** вы проектируете CI/CD-пайплайны для документации: от PR до публикации, включая валидацию, линтинг, сборку, деплой.

* **Governance:** вы определяете политику работы с Git для всей организации: какие ветки обязательны, какие проверки обязательны, кто и как может мержить.

* **Обучение и менторство:** вы обучаете инженеров и писателей работе с Git в контексте документации.

* **Ключевой принцип Senior:** вы определяете правила игры и отвечаете за их соблюдение в масштабе.

Курсы и книги (Senior)

[Module 11: Version Control for Documentation (TECH-OPSS)](https://github.com/TECH-OPSS/Technical-Writing-Masterclass) - Продвинутый модуль для senior-писателей и content architects: multi-branch workflows, CI/CD-гейты, compliance. Прямая ссылка на модуль недоступна, но материалы входят в репозиторий TECH-OPSS на GitHub;

[Docs as Code Infrastructure (TECH-OPSS)](https://github.com/TECH-OPSS/Technical-Writing-Masterclass) - Инфраструктурные паттерны для docs-as-code: модульная структура, мультиязычность, автоматизация. Прямая ссылка на модуль недоступна, материалы находятся в том же репозитории TECH-OPSS;

[«Docs for Developers» (Jared Bhatti et al.)](https://docsfordevelopers.com/) - Не про Git напрямую, но про то, как строить документацию в масштабе: архитектура, процессы, метрики, команда;

[«Pro Git» (главы 8–10)](https://git-scm.com/book/en/v2) - Главы о настройке Git, Git в организации, Git internals — для Senior-уровня (полный текст книги, включая главы 8–10, доступен на этой странице);

[Git Workflows (gitworkflows(7))](https://git-scm.com/docs/gitworkflows) - Официальное описание рабочих процессов Git для больших проектов;

[Git Branching Strategies for Documentation Projects (Redocly)](https://redocly.com/blog/git-branching-for-docs) - Разбор стратегий ветвления с рекомендациями для разных сценариев.
