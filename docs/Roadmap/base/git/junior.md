## Junior: «Коммичу и не боюсь»

На Junior-уровне Git — это ваш ежедневный инструмент. Вы должны уверенно выполнять базовые операции, не заглядывая в шпаргалку, и понимать зачем каждая из них нужна. Ключевой сдвиг в мышлении: вы перестаёте думать файлами и начинаете думать изменениями. Традиционный редактор перезаписывает файл — нет истории, нет точки восстановления. Git создаёт структурированную временную линию: каждый коммит — это снимок всей документации в конкретный момент, с записанным решением и возможностью отката.

Что входит в Junior-уровень:

* **Базовые команды**: git clone, git add, git commit, git push, git pull, git status, git log, git diff.

* **Ветвление**: создание ветки (git branch, git checkout -b), переключение, слияние (git merge). Понимание, что ветка — это «параллельная вселенная» для одной группы изменений.

* **Коммиты**: осмысленные сообщения (что и зачем изменено), разделение работы на небольшие логические шаги.

* **Pull Request**: создание PR на GitHub, описание изменений, запрос ревью, ответ на комментарии.

* **Работа с GitHub**: создание репозитория, README, issues, fork.

* **Понимание docs-as-code**: зачем писателю Git, как документация живёт в том же репозитории, что и код.

*Ключевой принцип Junior: вы следуете установленному воркфлоу. Если в команде принято создавать ветку для каждой задачи — вы делаете именно так.*

## Курсы и книги (Junior)

[Git and GitHub for Writers (Udemy)](https://www.udemy.com/course/git-and-github-for-writers/) - первый курс, созданный специально для писателей: все примеры — документы, а не код. 14 практических упражнений, объяснение концепций на языке, понятном писателю;

[Learn Git Branching](https://learngitbranching.js.org/) - визуализация ветвления — лучший способ увидеть, как работает Git. Визуальный sandbox и серия учебных задач;

[GitHub Skills](https://skills.github.com/) - курсы прямо внутри GitHub: «Introduction to GitHub», «Review Pull Requests», «Resolve Merge Conflicts». Учитесь в реальном репозитории с ботом Mona;

[Git and GitHub for Technical Writers](https://github.com/Douglasebhoman/git-github-for-technical-writers-series) - шесть серия именно для технических писателей: от основ Git до CI/CD и архитектуры репозитория;

[«Pro Git» (Скотт Чакон, Бен Штрауб)](https://git-scm.com/book/ru/v2) - официальная книга по Git, переведена на русский. Первые 3 главы — обязательно для Junior.

[«Git для профессионального программиста»](https://www.chitai-gorod.ru/product/git-dlya-professionalnogo-programmista-2618344) - русскоязычное издание про git.
