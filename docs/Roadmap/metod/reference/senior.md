## Senior: «Определяю стандарт и масштабирую»

На Senior-уровне reference становится **элементом стратегии документации**. Вы определяете, как справочная система вписывается в общую архитектуру документации.

**Что входит в Senior-уровень:**

- **Стратегия reference:** вы определяете, какие типы reference обязательны для каждого продукта (API reference, configuration reference, error code catalog, glossary), как они связаны с другими типами документации.
- **Governance:** вы определяете политику: кто отвечает за актуальность reference, как проверяется точность, как обрабатываются изменения в API.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых endpoints, версий, языков без полной перестройки.
- **Кросс-продуктовый reference:** вы обеспечиваете, чтобы reference для одного API связывался с reference для другого, не теряя контекст.
- **Метрики:** вы измеряете эффективность reference на уровне организации: time-to-find, support tickets, adoption.
- **Обучение:** вы обучаете команды проектированию reference, проводите воркшопы, создаёте внутренние стандарты.

*Ключевой принцип Senior: вы **определяете стандарт reference** для организации и отвечаете за его соблюдение.*

### Курсы и книги (Senior)

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды;

[Developing Quality Technical Information (IBM)](https://users.dcc.uchile.cl/~nbaloian/ArquitecturaDeLaInformacion/materialDeLAWeb/TriDoc2005-DQTI.pdf) - Главы о проектировании reference, точности, валидации;

[Information Architecture: For the Web and Beyond (Rosenfeld, Morville, Arango)](https://www.oreilly.com/library/view/information-architecture-4th/9781491913529/) - Классика IA: организация, навигация, связывание типов контента;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации в целом, включая reference и governance;

[Technical Communication (Mike Markel)](https://www.macmillanlearning.com/college/us/product/Technical-Communication/p/1319248727) - Главы о проектировании документов, аудиторном анализе, валидации.
