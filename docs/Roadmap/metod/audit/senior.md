## Senior: «Определяю стратегию и масштабирую»

На Senior-уровне аудиторный анализ становится **элементом организационной стратегии**.

**Что входит в Senior-уровень:**

- **Стратегия аудитории:** вы определяете, какие сегменты аудитории существуют для каждого продукта, как они связаны между собой, как их потребности влияют на roadmap документации.
- **Governance:** вы определяете политику: кто отвечает за аудиторный анализ, как часто он обновляется, как результаты анализа влияют на решения.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых продуктов, сегментов, языков без полной перестройки.
- **Кросс-продуктовый анализ:** вы обеспечиваете, чтобы аудиторный анализ для одного продукта связывался с анализом для другого.
- **Метрики:** вы измеряете эффективность аудиторного анализа на уровне организации: adoption, retention, support tickets, CSAT.
- **Обучение:** вы обучаете команды проведению аудиторного анализа, проводите воркшопы, создаёте внутренние стандарты.
- **Влияние на продукт:** вы используете понимание аудитории для влияния на продуктовые решения.

*Ключевой принцип Senior: вы **определяете стратегию аудитории** для организации.*

### Курсы и книги (Senior)

[Information Development: Managing Your Documentation, Projects, Portfolio, and People (JoAnn Hackos)](https://dl.acm.org/doi/book/10.5555/1190163) - Управление документацией и аудиторией в масштабе: процессы, метрики, команда;

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, работа с аудиторией, масштабирование, обучение команды;

[Technical Communication (Mike Markel, продвинутые главы)](https://www.macmillanlearning.com/college/us/product/Technical-Communication/p/1319248727) - Продвинутые главы: writing for multiple audiences, revising information for a new audience and purpose;

[Audience Personas: Audience Analysis Documentation for Rhetorical Technical Communications (CPTSC)](https://www.cptsc.org/) - Шаблон аудиторной персоны для технических коммуникаторов: как использовать персоны для sharing target audience среди writers, editors, media publishers;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации, включая аудиторный анализ и governance.
