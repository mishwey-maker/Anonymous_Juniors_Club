## Senior: «Определяю стандарт и масштабирую»

На Senior-уровне tutorial и how-to становятся **элементами стратегии документации**. Вы определяете, как эти типы вписываются в общую систему обучения пользователя, как они масштабируются на несколько продуктов и команд.

**Что входит в Senior-уровень:**

- **Стратегия типов документации:** вы определяете, как tutorial, how-to, reference и explanation работают вместе для каждого продукта.
- **Governance:** вы определяете политику: какие типы обязательны для каждого продукта, как проверять качество, как поддерживать актуальность.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых продуктов, языков, версий без полной перестройки.
- **Кросс-продуктовые tutorial:** вы обеспечиваете, чтобы tutorial для одного продукта связывался с tutorial для другого, не теряя контекст.
- **Обучение:** вы обучаете команды принципам Diátaxis, проводите воркшопы, создаёте внутренние стандарты.
- **Метрики:** вы измеряете эффективность tutorial и how-to на уровне организации: time-to-first-success, support tickets, retention.

*Ключевой принцип Senior: вы **определяете правила игры** и **отвечаете за их соблюдение в масштабе**.*

### Курсы и книги (Senior)

[Diátaxis Framework — Diátaxis as a guide to work](https://diataxis.fr/) - Продвинутое применение фреймворка: как использовать Diátaxis как руководство, а не план;

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды;

[Information Architecture: For the Web and Beyond (Rosenfeld, Morville, Arango)](https://www.oreilly.com/library/view/information-architecture-4th/9781491913529/) - Классика IA: организация, навигация, связывание типов контента;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации в целом, включая типы контента и governance;

[Technical Communication (Mike Markel)](https://www.macmillanlearning.com/college/us/product/Technical-Communication/p/1319248727) - Главы о проектировании документов, аудиторном анализе, валидации.
