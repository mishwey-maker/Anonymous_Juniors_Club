## Junior: «Различаю и пишу по шаблону»

На Junior-уровне вы учитесь **различать** how-to и tutorial и писать оба типа по готовым шаблонам. Ключевой сдвиг: вы перестаёте писать «инструкцию вообще» и начинаете осознанно выбирать формат под задачу читателя.

**Что входит в Junior-уровень:**

- **Понимание разницы:** tutorial учит (читатель не знает ничего), how-to решает (читатель знает контекст). Tutorial — это обучающий опыт для новичка, how-to — практическое руководство для опытного пользователя.
- **Структура tutorial:** заголовок начинается с глагола («Создайте первый REST API»), структура — Goal → Prerequisites → Numbered steps → Immediate verifiable result at each step → Final outcome.
- **Структура how-to:** заголовок формулируется как задача («Как настроить X»), структура — Goal statement → Assumptions/prerequisites → Numbered steps → Expected result.
- **Шаблоны:** вы используете готовые шаблоны для обоих типов: Overview → Prerequisites → Steps → Examples → Troubleshooting.
- **Проверка на работоспособность:** вы тестируете свой tutorial или how-to, проходя по шагам самостоятельно.

*Ключевой принцип Junior: вы **следуете** шаблону и осознанно выбираете формат под задачу читателя.*

### Курсы и книги (Junior)

[Google Technical Writing One](https://developers.google.com/tech-writing/one) - База: аудитория, активный залог, списки, структура. В Technical Writing Two есть раздел о создании примеров для туториалов;

[Diátaxis Framework](https://diataxis.fr/) - Официальный фреймворк: различие между tutorials и how-to guides, принципы каждого типа;

[GitLab Technical Writing Fundamentals Course](https://about.gitlab.com/handbook/product/ux/technical-writing/fundamentals/) - Четыре вводных видео о типах топиков, грамматике и стилевых требованиях;

[The idea of a tutorial (Ubuntu Blog)](https://ubuntu.com/blog/the-idea-of-a-tutorial) - Глубокое объяснение разницы между tutorial и how-to: tutorial — обучение, how-to — применение навыка;

[Awesome Technical Writing Learning (GitHub)](https://github.com/wongyah/awesome-technical-writing-learning) - Кураторский список бесплатных ресурсов по техническому писательству.
