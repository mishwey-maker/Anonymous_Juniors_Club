## Junior: «Пишу по шаблону и собираю типовые проблемы»

На Junior-уровне вы учитесь **распознавать** troubleshooting-сценарии и писать статьи по готовому шаблону.

**Что входит в Junior-уровень:**

- **Понимание структуры:** troubleshooting-статья строится по формату **Problem → Cause → Solution**. Заголовок должен описывать симптом, который видит пользователь.
- **Типы troubleshooting-контента:** вводный (контекст о возможных проблемах), task-based (пошаговое решение), reference (справочная информация о проблемах).
- **Структура KB-статьи:** Title → Problem/Symptom → Environment → Cause (если известна) → Resolution Steps → Verification → Related Articles.
- **Язык:** простой, спокойный, нейтральный тон. Избегайте жаргона, объясняйте технические термины кратко.
- **Разделение ошибок и решений:** не смешивайте описание проблемы с её решением в одном абзаце.
- **Поисковая оптимизация:** заголовок — самый важный элемент для поиска. Используйте формулировки, которые вводит пользователь.

*Ключевой принцип Junior: вы **пишете troubleshooting по шаблону**, начиная с симптома.*

### Курсы и книги (Junior)

[Troubleshooting documentation (GitLab Docs)](https://docs.gitlab.com/development/documentation/troubleshooting/) - Официальное руководство GitLab по troubleshooting-топикам: три типа контента, структура, примеры;

[Knowledge Base Articles (Progress Telerik Style Guide)](https://docs.telerik.com/devtools/wpf/styling-and-appearance/style-guide/knowledge-base-articles) - Разбор структуры KB-статьи: problem, cause, fixes, workarounds;

[Support Articles (DigitalOcean Docs)](https://www.digitalocean.com/community/tutorials) - Практические рекомендации: lead with the resolution, break problems into failure points, separate errors from solutions;

[Google Technical Writing One](https://developers.google.com/tech-writing/one) - База: аудитория, структура, ясность. Применимо к troubleshooting;

[How to Structure an IT Knowledge Base Article (Ones.com)](https://ones.com/blog/how-to-structure-an-it-knowledge-base-article/) - Шаблон KB-статьи: Title, Problem/Symptom, Environment, Resolution Steps, Verification.
