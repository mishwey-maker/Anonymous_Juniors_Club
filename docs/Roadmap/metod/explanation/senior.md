## Senior: «Определяю стандарт и масштабирую»

На Senior-уровне explanation становится **элементом стратегии документации**.

**Что входит в Senior-уровень:**

- **Стратегия explanation:** вы определяете, какие концепции обязательны для каждого продукта (architecture overview, design rationale, data model explanation), как они связаны с tutorial, how-to и reference.
- **Governance:** вы определяете политику: кто отвечает за explanation, как проверяется качество, как обрабатываются изменения в архитектуре.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых продуктов, концепций, языков без полной перестройки.
- **Кросс-продуктовые explanation:** вы обеспечиваете, чтобы explanation для одного продукта связывался с explanation для другого.
- **Метрики:** вы измеряете эффективность explanation на уровне организации: снижение support tickets, ускорение onboarding, adoption.
- **Обучение:** вы обучаете команды написанию explanation, проводите воркшопы, создаёте внутренние стандарты.

*Ключевой принцип Senior: вы **определяете стандарт explanation** для организации.*

### Курсы и книги (Senior)

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды;

[Developing Quality Technical Information (IBM)](https://users.dcc.uchile.cl/~nbaloian/ArquitecturaDeLaInformacion/materialDeLAWeb/TriDoc2005-DQTI.pdf) - Продвинутые главы: проектирование explanation, валидация, метрики;

[Information Architecture: For the Web and Beyond (Rosenfeld, Morville, Arango)](https://www.oreilly.com/library/view/information-architecture-4th/9781491913529/) - Классика IA: организация, навигация, связывание типов контента;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации, включая explanation и governance;

[Technical Communication (Mike Markel)](https://www.macmillanlearning.com/college/us/product/Technical-Communication/p/1319248727) - Главы о проектировании документов, аудиторном анализе, валидации.
