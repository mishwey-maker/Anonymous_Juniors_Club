## Junior: «Пишу по шаблону и собираю изменения»

На Junior-уровне вы учитесь **распознавать** разницу между release notes и changelog и писать оба типа по готовому шаблону.

**Что входит в Junior-уровень:**

- **Понимание разницы:** release notes — для пользователей (benefit-led, action-oriented), changelog — для разработчиков (precise, structured, technical).
- **Структура release notes:** заголовок с версией и датой → Highlights → New Features → Improvements → Bug Fixes → Breaking Changes → Deprecation → ссылки на документацию.
- **Структура changelog:** дата + версия → категории: Added, Changed, Deprecated, Removed, Fixed, Security.
- **Сбор изменений:** вы умеете читать merged PRs, closed tickets, commit messages и вытаскивать из них то, что важно для пользователя.
- **Язык:** вы пишете простым языком («Export to CSV» вместо «Enhanced data portability»), избегаете жаргона и внутренних названий фич.
- **Что не включать:** internal refactors, branch names, ticket IDs, vague engineering notes, PR numbers, commit hashes.

*Ключевой принцип Junior: вы **пишете release notes и changelog по шаблону**, собирая изменения из PR и тикетов.*

### Курсы и книги (Junior)

[Technical Writing for Software Development (Pluralsight)](https://www.pluralsight.com/courses/technical-writing-software-documentation) - Раздел о release notes: как коммуницировать завершённую работу через release notes и support content;

[How to write release notes (Mintlify)](https://mintlify.com/blog/how-to-write-release-notes) - Детальный разбор разницы между release notes и changelog, шаблоны для product и API releases;

[How to Write a Changelog (AnnounceKit)](https://announcekit.app/blog/how-to-write-a-changelog) - Best practices для changelog: структура, категории, примеры хороших и плохих записей;

[Keep a Changelog](https://keepachangelog.com/) - Официальный стандарт changelog: категории Added, Changed, Deprecated, Removed, Fixed, Security;

[Changelog vs. Release Notes (AnnounceKit)](https://announcekit.app/blog/changelog-vs-release-notes) - Шесть различий между changelog и release notes: аудитория, цель, контент, формат, тон, тайминг.
