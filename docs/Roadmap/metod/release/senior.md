## Senior: «Определяю стандарт и масштабирую»

На Senior-уровне release notes и changelog становятся **элементами стратегии коммуникации**.

**Что входит в Senior-уровень:**

- **Стратегия коммуникации:** вы определяете, какие типы изменений доносятся через какие каналы: release notes (пользователи), changelog (разработчики), email digests (stakeholders), in-app notifications (end users).
- **Governance:** вы определяете политику: кто отвечает за release notes, как проверяется точность, как обрабатываются breaking changes.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых продуктов, версий, языков без ручной работы.
- **Кросс-продуктовый changelog:** вы обеспечиваете, чтобы changelog для одного API связывался с changelog для другого.
- **Метрики:** вы измеряете эффективность коммуникации изменений на уровне организации: adoption новых фич, support tickets, retention.
- **Обучение:** вы обучаете команды писать release notes, проводите воркшопы, создаёте внутренние стандарты.

*Ключевой принцип Senior: вы **определяете стандарт коммуникации изменений** для организации.*

### Курсы и книги (Senior)

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды;

[Developing Quality Technical Information (IBM)](https://users.dcc.uchile.cl/~nbaloian/ArquitecturaDeLaInformacion/materialDeLAWeb/TriDoc2005-DQTI.pdf) - Продвинутые главы о проектировании release notes, валидации, метриках;

[Information Architecture: For the Web and Beyond (Rosenfeld, Morville, Arango)](https://www.oreilly.com/library/view/information-architecture-4th/9781491913529/) - Классика IA: организация, навигация, связывание типов контента;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации, включая release notes и governance;

[Spring Into Technical Writing for Engineers and Scientists (Rosenberg)](https://www.pearson.com/store/p/spring-into-technical-writing-for-engineers-and-scientists/P100000855156) - Разделы о release notes и manuals: how to write effective release notes.
