## Senior: «Определяю стандарт и проектирую архитектуру»

На Senior-уровне CI/CD становится **элементом архитектуры документации**. Вы не просто настраиваете пайплайн для одного проекта, вы **определяете стандарт для организации**, проектируете масштабируемую систему и управляете lifecycle CI/CD.

**Что входит в Senior-уровень:**

- **Стратегия CI/CD для документации:** вы определяете, какие проверки обязательны для всех docs-репозиториев, какие инструменты используются, как обрабатываются исключения.
- **Governance:** вы определяете политику: кто отвечает за обновление CI/CD, как обрабатываются breaking changes в пайплайне, как проверяется качество сборки.
- **Масштабирование:** вы проектируете систему, которая выдерживает рост: добавление новых продуктов, языков, версий без переписывания workflow для каждого.
- **Стандартизация workflow:** вы создаёте reusable workflows (GitHub Actions) или templates (GitLab CI), которые используются всеми командами. Вы определяете, какие проверки обязательны, какие — опциональны.
- **Интеграция с другими системами:** вы интегрируете CI/CD документации с системами аналитики (проверка качества после деплоя), системами мониторинга (уведомления), системами управления релизами (синхронизация с версиями продукта).
- **Метрики:** вы измеряете эффективность CI/CD: время сборки, частота падений, время до исправления, покрытие проверками.
- **Обучение:** вы обучаете команды работе с CI/CD, проводите воркшопы, создаёте внутренние стандарты.

*Ключевой принцип Senior: вы **определяете правила игры** и **отвечаете за их соблюдение в масштабе**. CI/CD для документации становится частью инженерной культуры компании.*

### Курсы и книги (Senior)

[GitHub Actions: Advanced Techniques (Pluralsight)](https://www.pluralsight.com/courses/github-actions-advanced) - Продвинутые темы: reusable workflows, composite actions, matrix builds, кэширование, безопасность;

[Continuous Delivery: Reliable Software Releases through Build, Test, and Deployment Automation (Jez Humble, David Farley)](https://www.oreilly.com/library/view/continuous-delivery-reliable/9780321670250/) - Классика CI/CD: принципы, паттерны, антипаттерны. Применимо к документации как к части software delivery;

[Accelerate: The Science of Lean Software and DevOps (Nicole Forsgren et al.)](https://itrevolution.com/product/accelerate/) - Научный подход к измерению эффективности CI/CD: DORA-метрики, которые можно адаптировать для документации;

[Docs for Developers (Jared Bhatti et al.)](https://link.springer.com/book/10.1007/978-1-4842-7295-1) - Стратегия документации, архитектура, масштабирование, обучение команды;

[Write the Docs: Software Documentation Guide](https://www.writethedocs.org/guide/) - Best practices для документации, включая CI/CD и governance.
