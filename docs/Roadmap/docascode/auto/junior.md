## Junior: «Понимаю принцип и запускаю готовую генерацию»

На Junior-уровне автоматизация генерации — это **осознание того, что документацию можно создавать не только вручную**. Вы учитесь запускать готовые генераторы, понимать, откуда берётся контент, и проверять, что сгенерированная документация соответствует реальности. Ключевой сдвиг: вы перестаёте воспринимать документацию как «текст, который я пишу» и начинаете видеть в ней **результат работы инструмента**, который можно настроить.

**Что входит в Junior-уровень:**

- **Понимание источников генерации:** документация может генерироваться из разных источников: OpenAPI-спецификации (Swagger Codegen, Redocly), комментариев в коде (Javadoc, DocFX, Sphinx), AST-анализа кода (know-cli, code2docs). Вы знаете, что каждый источник даёт разный результат.
- **Запуск готового генератора:** вы умеете запустить генератор документации из OpenAPI-файла: `swagger-codegen generate` или `redocly build-docs`. Вы видите результат и понимаете, как спецификация превращается в HTML или Markdown.
- **Генерация reference из кода:** вы понимаете, как работает генерация API reference из комментариев в коде (docstrings, Javadoc). Вы можете запустить `sphinx-apidoc` или `docfx` и увидеть, как комментарии становятся документацией.
- **Проверка результата:** вы проверяете, что сгенерированная документация соответствует реальному API: правильные эндпоинты, параметры, примеры. Если что-то не совпадает — вы сообщаете об этом.
- **Понимание ограничений:** вы знаете, что автогенерация покрывает reference, но не даёт контекста, объяснений и примеров использования. Вы понимаете, что ручная работа всё ещё нужна — но в другом месте.

*Ключевой принцип Junior: вы **запускаете и проверяете** готовую генерацию. Вы не настраиваете пайплайн, а учитесь работать с результатом.*

### Курсы и книги (Junior)

[Внедрение автоматизации документации истории Git (Microsoft Learn)](https://learn.microsoft.com/en-us/training/modules/automate-documentation/) - Официальный модуль: автоматизация документации API из кода через OpenAPI, Swagger Codegen, Redocly. Встраивание в CI/CD;

[DocFX Documentation](https://dotnet.github.io/docfx/) - Официальная документация DocFX: генерация reference из комментариев в коде для .NET, Java, JavaScript;

[Sphinx Documentation](https://www.sphinx-doc.org/) - Официальная документация Sphinx: генерация reference из docstrings для Python;

[Swagger Codegen Documentation](https://swagger.io/tools/swagger-codegen/) - Официальная документация Swagger Codegen: генерация документации из OpenAPI;

[Redocly CLI Documentation](https://redocly.com/docs/cli/) - Официальная документация Redocly CLI: генерация документации из OpenAPI.
