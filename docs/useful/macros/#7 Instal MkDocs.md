#### Установка MkDocs

1. Установить генератор *MkDocs*. Для этого откройте CMD и выполните команду:

```shell
pip install mkdocs
```

2. Установить тему *MkDocs material theme* с помощью команды:

```shell
pip install mkdocs-material
```

3. Перейти в папку с репозиторием проекта с помощью команды ```cd путь_к_папке```;

4. Проверить состояние проекта с помощью команды ```git status```. Убедится, что находитесь в главной ветке. Если нет, переключитесь на неё (команда ```git switch main```);

5. Обновить репозиторий с помощью команды ```git pull```;

6. Отколоть новую ветку, в которой будет совершаться настройка проекта. Например *task-2-setup-mkdocs*;
7. Открыть папку проекта через проводник;
8. В папке создать *mkdocs.yml*. Это конфиг, с помощью которого будет происходить настройка документации;
9. Привести структуру проекта к шаблону:

```
├─ docs/
│  └─ index.md
└─ mkdocs.yml
```

По шаблону все исходники должны лежать в подпапке docs. Создать папку *docs* и перенести туда файл *index.md*;
10. Открыть файл mkdocs.yml (с помощью VS Code или любого другого редактора кода) и добавить  название проекта:
```site_name: [Название сайта]```
11. Сохранить изменения в *mkdocs.yml* и закрыть файл.

12. Выполнить команду ```mkdocs serve```
Если всё сделано правильно, в ответ придёт адрес локального порта, на котором собралась дока:
```shell
C:\Users\User1\parawriter\parawriter_docs>mkdocs serve
INFO    -  Building documentation...
INFO    -  Cleaning site directory
INFO    -  Documentation built in 0.11 seconds
INFO    -  [11:59:50] Watching paths for changes: 'docs', 'mkdocs.yml'
INFO    -  [11:59:50] Serving on http://127.0.0.1:8000/
```
Если перейти по адресу в последней строке, то можно увидеть как будет выглядеть сайт.

Теперь дело за малым: закоммитьте изменения, отправьте их на сервер, создайте пул-реквест и влейте рабочую ветку в ветку main. 

13. Выполнить команду ```-git add .```

14. Выполнить команду ```git commit -m "краткое описание изменений"```.

15. В GitHub выберите пункт *Pull requests*. 
16. Нажать кнопку *New pull request*.
17. В разделе *«Compare changes»* выбрать ветки: 
В поле base нужно добавить ветку main, а в поле compare — ветку с которой ведётся работа.
18. Нажать кнопку *Create pull request*.
19. Заполнить описание пул-реквеста.
20. Нажать кнопку *Create pull request*.
