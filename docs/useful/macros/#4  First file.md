### Первый файл

1. Открыть CMD и перейти в папку проекта с помощью команды ```cd путь_к_папке```;

2. Проверить состояние проекта, выполнив команду ```git status```
>Что нужно смотреть в статусе репозитория? То, что вы находитесь в нужной ветке (main) и что у вас нет незафиксированных изменений;

3. Обновить репозиторий, выполнив команду ```git pull```. 
>Эта команда забирает актуальную версию ветки из оригинального репозитория на наш компьютер. Сейчас таких изменений нет, но мы будем следовать правилам;

3. Каждая новая задача (а перед нами стоит задача добавить первый файл) должна выполняться в отдельной ветке. Создать новую ветку ```task-1-add-file```, отколов её от ветки ```main```. Для этого выполнить команду ```git branch task-1-add-file```

4. Новая ветка создана, но *git status* покажет, что вы до сих пор находится в ветке *main*. Чтобы переключиться на рабочую ветку, выполнить команду ```git switch task-1-add-file```;

5. В папке проекта создать файл index.md. 

6. После создания нового файла нам нужно отправить его на сервер:

7. Вернуться в CMD и снова выполните команду ```git status```. Система показывает, что в проекте есть изменения:
```shell
C:\Users\User1\parawriter\parawriter_docs>git status
On branch task-1-add-file
Untracked files:
  (use "git add <file>..." to include in what will be committed)
        index.md

nothing added to commit but untracked files present (use "git add" to track)
```
8. Перед тем, как создать коммит, нужно сообщить гиту, какие изменения требуется зафиксировать в коммите. Для этого используется команда ```git add```. Так как мы собираемся зафиксировать все изменения, выполнить команду в таком виде: ```git add .```;

9. Теперь файл *index.md* проиндексирован. Для создания коммита выполнить команду ```git commit -m "краткое описание изменений"```:

```shell
C:\Users\User1\parawriter\parawriter_docs>git commit -m "Добавил новый файл index.md"
[task-1-add-file df62424] Добавил новый файл index.md
 1 file changed, 0 insertions(+), 0 deletions(-)
 create mode 100644 index.md
```
>Система сообщает о том, что изменения зафиксированы.

Отправить коммит на сервер, выполнив команду ```git push```. Так как вашей рабочей ветки ещё нет на сервере, используйте команду с флагом ```set-upstream: git push --set-upstream origin task-1-add-file```. Это нужно только для первого обновления, все последующие обновления ветки можно будет проводить командой ```git push``` без флага;

файл index.md отправился на сервер. Нам осталось создать пул-реквест и слить рабочую ветку и ветку main, чтобы обновить проект.
